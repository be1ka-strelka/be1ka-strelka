# Описание проекта

## Структура описания

**Название** — «Аналитика дисциплины тренеров» (Teacher Analytics).

**Проблема** — руководитель команды тренеров в школе детского развития
ежемесячно получает Excel-таблицы с показателями дисциплины (отмены,
переносы, замены, количество учеников). Сводить их вручную долго и
чревато ошибками. Нужен инструмент, который мгновенно превращает сырые
таблицы в наглядный отчёт по каждому тренеру и по школе в целом.

**Пользователь** — руководитель команды тренеров и менеджеры школы
детского развития. Технического бэкграунда не требуется: достаточно
загрузить файлы в браузере.

**Основная функция**
- **Вход:** один или несколько Excel-файлов (по месяцам), лист
  «Дисциплина» со стандартными колонками.
- **Обработка:** парсинг и валидация структуры, агрегация по ID тренера,
  расчёт метрик, построение динамики и прогноза.
- **Выход:** интерактивный веб-отчёт — сводка по школе, карточка каждого
  тренера с линейным графиком динамики учеников и столбчатой диаграммой
  дисциплины, топ/антитоп тренеров, прогноз на лето, полная таблица с
  поиском.
- **Инструменты:** Python, Flask, openpyxl, Chart.js.

**Формат результата** — визуальный дашборд в браузере (локально). Цифры
считаются детерминированно на сервере, без участия ИИ → повторяемо и
точно.

**Минимальный функционал (MVP — реализовано)**
1. Отмены по инициативе тренера
2. Отмены по инициативе ученика
3. Переносы по инициативе тренера
4. Переносы по инициативе ученика
5. Линейный график динамики количества учеников при выборе тренера
6. Прогноз показателей на летний период (июнь–август)
7. Тренеры с наибольшим числом переносов/замен по инициативе тренера
8. Тренеры с наименьшим числом переносов/замен по инициативе тренера

Замены и отмены считаются и отображаются **раздельно**.

**Планы на будущее**
- Экспорт отчёта в PDF/Excel.
- Сравнение периодов год к году.
- Загрузка файла каникул/отпусков для точного прогноза вместо
  коэффициентов.

**Технологии** — Python 3, Flask (бэкенд и роутинг), openpyxl (чтение
Excel), HTML/CSS + JavaScript, Chart.js (графики). Формат обмена
фронтенд↔бэкенд — JSON.

## Методика прогноза на лето

В исходных данных есть только весенние месяцы (февраль–май), летних —
нет. Прогноз строится от среднего весеннего уровня с коэффициентами
сезонного спада. Логика: конец учебного года + сезон отпусков снижают
спрос на ментальную арифметику, скорочтение, подготовку к школе и
экзаменам; часть учеников уезжает.

Множители спада к среднему весеннему уровню:
- **июнь ×0.70** — учебный год только закончился, часть продолжает ходить
- **июль ×0.50** — пик отпусков, минимум спроса
- **август ×0.65** — начинается подготовка к школе, частичное возвращение

Отмены и переносы по инициативе ученика летом повышены **×1.6**
(отпуска, отъезды).

**Источники статистики сезонности:**
- Gallup (2024): «In U.S., 45% of Children Lack Summer Learning
  Opportunities» — лишь ~55% детей участвуют хотя бы в одной
  структурированной летней активности.
  https://news.gallup.com/poll/647015/children-lack-summer-learning-opportunities.aspx
- EdWeek (2023): «The State of After-School and Summer Programs» — менее
  1 из 5 школьников участвует в академических летних программах.
  https://www.edweek.org/leadership/the-state-of-after-school-and-summer-programs-in-charts/2023/11

Коэффициенты — экспертная оценка на основе этих данных; их легко
скорректировать в `app/analytics.py` (`SUMMER_FACTORS`,
`SUMMER_STUDENT_CANCEL_UPLIFT`), либо заменить на реальный файл
каникул/отпусков, когда он появится.
