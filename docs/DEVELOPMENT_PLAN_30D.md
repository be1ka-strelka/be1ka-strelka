# Личный план развития на 30 дней

## Вектор развития
**Агентные системы + автоматизация аналитики** (на стыке с SaaS).
Развиваю навык создания персональных агентов и инструментов, которые
превращают рутинную работу с данными в готовый продукт.

## Проект месяца
**Teacher Analytics** — сервис анализа Excel-таблиц дисциплины тренеров
школы детского развития. Развиваю из MVP в готовый рабочий инструмент.

## Маршрут проекта

**Для кого:** руководитель команды тренеров и менеджеры школы детского
развития (без технического бэкграунда).

**Какой сценарий должен работать:**
Пользователь открывает локальный сайт → загружает Excel-файлы по месяцам
→ за секунды получает визуальный отчёт: сводку по школе, динамику
учеников по каждому тренеру, топ/антитоп по дисциплине, прогноз на лето →
может выгрузить отчёт для руководства.

**Как проверю результат:**
- Сервис запускается локально и отвечает 200 на `http://127.0.0.1:5000`.
- Реальные данные (4 месяца, 76 тренеров) обрабатываются без ошибок.
- Битые/неверные файлы дают понятную ошибку, а не падение.
- Цифры расчётов сверяю вручную по нескольким тренерам.

**Как буду презентовать:**
- README с пошаговой инструкцией запуска.
- Описание проекта по шаблону (`docs/PROJECT.md`).
- Демонстрация: загрузка файлов → отчёт → графики → экспорт.
