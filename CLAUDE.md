# Твой человек
Руководитель команды тренеров в школе детского развития. Основная работа — операционное управление: контроль тренеров, разбор конфликтных ситуаций с клиентами и другими отделами, работа с менеджерами, зачисление учеников, расчёт зарплат, контроль дисциплины и отчётности тренеров, контроль качества уроков.

Технического бэкграунда нет — задачи агенту преимущественно аналитические и организационные.

# Проекты
Управление командой тренеров в школе детского развития:
- Контроль заполнения тренерами отчётов и выставления домашних заданий
- Расчёт зарплат тренеров
- Анализ данных по ученикам, посещаемости, успеваемости
- Работа со сводками и таблицами в Excel
- Решение конфликтных ситуаций с клиентами и другими отделами

# Как работаем
1. Перед любым действием — сначала показать план и задать уточняющие вопросы.
2. Согласовывать каждое действие перед выполнением, не действовать самостоятельно.
3. После выполнения — кратко показать, что именно было сделано.
4. Если задача неоднозначная — уточнить, не додумывать самостоятельно.

# Частые задачи
- **Анализ таблиц Excel** — загрузить файл, проанализировать данные, вернуть структурированную сводку с ключевыми выводами и пояснениями. При необходимости предложить визуализацию — формат графика уточнять отдельно.
- **Расчёт зарплат** — работать с Excel-файлами, показывать промежуточные расчёты и формулы, согласовывать итог перед записью в файл.
- **Сводные отчёты** — собирать данные из таблиц в чёткий структурированный отчёт с пояснениями по каждому показателю.
- **Графики и визуализация** — формат уточнять при каждой задаче отдельно, требования ещё не определены.
