# excel-report

Скил для работы с месячными Excel-таблицами дисциплины тренеров школы
детского развития.

## Когда использовать
- Нужно прочитать один или несколько `*.xlsx` из папки `data/`.
- Нужно проверить, что структура файла корректна (8 колонок, лист
  «Дисциплина»).
- Нужно посчитать сводку, динамику учеников или прогноз на лето без
  запуска веб-сервера.

## Ожидаемая структура файла
Лист `Дисциплина`, заголовки в первой строке строго в порядке:

```
ID тренера | Общее кол-во уроков | Количество учеников |
Отмены по инициативе тренера | Замены по инициативе тренера |
Переносы по инициативе тренера | Переносы по инициативе ученика |
Отмены по инициативе ученика
```

Месяц определяется по имени файла (`февраль.xlsx` → февраль).

## Как пользоваться (из кода)
Ядро лежит в `app/analytics.py`. Пример быстрого прогона по папке:

```python
import sys; sys.path.insert(0, "app")
import glob, analytics

files = [(p.split("\\")[-1], open(p, "rb").read())
         for p in glob.glob(r"..\data\*.xlsx")]
res = analytics.aggregate(files)

print(res["months"])              # порядок месяцев
print(res["totals"])              # итоги по школе
print(res["tops"]["most"])        # больше всего переносов/замен (тренер)
print(res["tops"]["least"])       # меньше всего
print(res["summer_forecast"])     # прогноз июнь-август
```

## Правила (из Halper.md)
- Не изменять и не перезаписывать исходные Excel-файлы.
- Замены и отмены считать и показывать **раздельно**.
- При непонятной/несовпадающей структуре — не додумывать, вернуть
  понятную ошибку (`ValidationError`) и сообщить пользователю.
- Данные касаются детей и клиентов — не передавать третьим сторонам.

## Ключевые функции
- `parse_workbook(file_bytes, filename)` — читает один файл, валидирует.
- `aggregate(files)` — агрегирует список `(имя, bytes)` в полный отчёт.
- `summer_forecast(...)` — прогноз на лето по коэффициентам
  (`SUMMER_FACTORS`); методика и источники в `docs/PROJECT.md`.
